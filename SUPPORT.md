# Support

Use [GitHub Discussions](https://github.com/vantasnerdan/substrate-framework/discussions)
for setup questions, API usage, and early design conversation. Search existing
documentation and discussions first.

Open an issue when there is a concrete bug, documentation defect, or scoped
positive contribution objective. Every pull request must have exactly one
canonical issue created before the pull request.

For security vulnerabilities, use the private channel in
[`SECURITY.md`](SECURITY.md). For conduct concerns, follow
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). These channels should not be used
for ordinary scientific disagreement, which belongs in a sourced proposal or
claim review.
