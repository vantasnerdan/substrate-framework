## Frozen invariants and conventions

charge is `Q=integral rho_q`, and a gauge-field rescaling cannot be counted as
a physical prediction without fixing the compact holonomy normalization and a
matter/tag observable.  The first task is to verify dimensions and rescaling
invariance of (1).  Classical conservation, topological integrality, canonical
action, prequantization, and quantum representation weight are separately
typed objects.

The tested mechanism must bind to the same carrier branch and leaf.  A
topological number in an unrelated field, a declared integer charge, or an
arbitrary initial KKS action does not select the carrier mode action.
