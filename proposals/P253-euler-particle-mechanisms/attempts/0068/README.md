`rho_m`, `div u=0`, and a smooth compactly supported or integrable signed tag

    rho_q=g chi,      J=g chi u.

    E=-grad phi-partial_t A,   B=curl A,

and the positive free-field plus source Lagrangian

    L_field=integral {epsilon |E|^2/2-|B|^2/(2 mu)} dx,
    L_gauge=L_field+integral {J dot A-rho_q phi} dx.

later substrate derivation selects them. The gauge-field characteristic speed
is `c=1/sqrt(epsilon*mu)` and does not select the charge/action normalization;
the coupled incompressible pressure sector remains elliptic and instantaneous.

exact and every new state variable and constant is explicit. Route C may
remain a named construction if the coupled local flow has not been proved,
but no 0042 inheritance is claimed without it. This attempt cannot earn P5 or
replace the Euler foundation by itself. It provides a concrete object for the
owner to accept, reject, or require to emerge from a later Euler collective

numerics or comparator values are licensed. Algebraic checks do not prove the
