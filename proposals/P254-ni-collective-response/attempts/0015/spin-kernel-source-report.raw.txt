## Summary

**The material bridge is available as an operator construction, not as a fitted interaction.** QE already implements the required coupled longitudinal-spin Hartree+PBE-GGA map:

```fortran
USE dv_of_drho_lr, ONLY : dv_of_drho
! work(dfftp%nnr,2) contains complex δn_up, δn_down
CALL dv_of_drho(work)
! work now contains δV_HXC,up, δV_HXC,down
```

It requires the registered ground-state background, `setup_dmuxc()`, `setup_dgc()`, the actual FFT descriptors and reciprocal-vector maps, and `qpoint%xq`. **The density space is the two-spin spatial FFT/PW space—not two scalar spin channels.**

The genuinely missing pieces in the inspected Ni/H exporter are:

1. Exporting—or exposing natively—this density-kernel action and its background coefficients.
2. Supplying density↔wavefunction actions and **full-PW bare perturbation RHSs**, rather than only retained-band vertex matrices.
3. A finite-\(z\), two-branch response driver with the correct occupations, static ensemble distinction, and \(q/-q\) bookkeeping.

No native calculation, build, test, modification, or renewed G10 review was performed.

Conversely, the collinear response input to `dv_of_drho` is **\((\delta n_\uparrow,\delta n_\downarrow)\)**: the routine explicitly sums these columns for Hartree. Do not feed it \((\delta n,\delta m)\) without conversion.

The ordinary periodic Hartree operation implemented there is

\[
\delta V_{H,\sigma}(G)=
\frac{e^2\,4\pi}
{\mathrm{tpiba}^2|G+q|^2}
\left[\delta n_\uparrow(G)+\delta n_\downarrow(G)\right].
\]

The singular \(G+q=0\) component is omitted. At Gamma, that goes together with the neutral-number constraint and potential gauge; it is not an independently adjustable interaction parameter. Preserve the actual electrostatic flags. In particular, `lrpa` drops XC, and `lnolr` changes the long-range Hartree operation; those are not the requested full kernel.

## Architecture: density, wavefunction, and external-operator actions

```text

    → dv_of_drho                         K_q
    → interpolate dense→smooth if needed
```

## Minimal functional linear system

**[INFERENCE / derived construction from the source operators; not an exercised material result.]**

Use the QE convention \(g_b^q=\partial h/\partial u_b^q\), and let:

- \(K_q\): the native `dv_of_drho` map;
- \(M_q\): multiplication by a local spin potential, implemented through the FFT/state application;
- \(N_q\): extraction of induced spin density from the density matrix;
- \(\gamma_0\): the registered electronic reference.

For \(\operatorname{Im}z>0\), with \(z\) expressed in the same energy units as the eigenvalues,

\[
[z-\mathcal L_{0,q}]\,\delta\gamma_q
=
\left[
\sum_b g_b^q u_b^q+M_qK_qN_q\delta\gamma_q,\,
\gamma_0
\right].
\]

In the eigenstate representation this means

\[
(\delta\gamma_q)_{mnk\sigma}
=
\frac{f_{nk\sigma}-f_{mk+q,\sigma}}
{z+\epsilon_{nk\sigma}-\epsilon_{mk+q,\sigma}}
\left[
\sum_b g_b^q u_b^q+M_qK_q\delta n_q
\right]_{mnk\sigma}.
\]

Let \(R^0_{AB}(q,z)\) denote response to an **additive** Hamiltonian perturbation \(+V_B\). Then

\[
\boxed{
[I-R^0_{nn}(q,z)K_q]\,\delta n_q
=
R^0_{ng}(q,z)u_q
}
\]

and the electronic external-side response is

\[
R^{\rm sc}_{gg}
=
R^0_{gg}
+
R^0_{gn}K_q
[I-R^0_{nn}K_q]^{-1}R^0_{ng}.
\]

Both external sides remain the **bare full local+nonlocal** \(g\). All internal screening is generated by the same-frequency density solve. No inference of \(K_q\) from \(g_{\rm screened}-g_{\rm bare}\) is involved.

### Finite-\(z\) implementation boundary

A full response contains both occupation-difference terms, equivalently two resolvent branches. A single static perturbed-ket solve followed by `2*Re` is insufficient for arbitrary complex \(q,z\).

`ch_psi_all_complex` supplies useful complex-shift Hamiltonian machinery, but:

- its `alpha_pv` shift must be removed for an unprojected resolvent, or its projected-out contributions must be restored consistently;
- static `orthogonalize` occupation weights cannot simply be reused at finite \(z\);
- `solve_e_fpol.f90:96,149-150` explicitly rejects LSDA and metallic/non-Gamma cases. It is **not** a ready Ni/H finite-q driver.

Using the static PBE Hessian at finite frequency defines the **adiabatic spin-PBE** extension. It does not supply XC memory, collision physics, or physical linewidths.

For the ionic action, the response is only one term:

\[
H^{\rm eff}_{ab}(q,z)
=
H^{\rm ion}_{ab}(q)
+\operatorname{Tr}(\gamma_0 W_{ab})
+R^{\rm sc}_{g_ag_b}(q,z),
\]

with \(W_{ab}=\partial_a\partial_b h_{\rm ion}\). QE already separates the explicit terms in `PHonon/PH/dynmat0.f90:44-68`: `dynmat_us`, `d2ionq`, and applicable corrections. `dynmat_us.f90:10-15` identifies its \(\langle\psi|V''-\epsilon S''|\psi\rangle\) contribution. Those terms must remain explicit, not be fitted from first-order vertices.

## Static ensemble and complex-q requirements

### Static populations are not the isolated \(z\to0\) limit

The registered static objective fixes total \(N\) and lets magnetization relax. Its static FD response therefore needs:

\[
(\delta\gamma)_{nn}
=f'_n\big[(\delta V)_{nn}-\delta\mu\big],
\qquad
\delta N=0,
\]

with **one common** \(\delta\mu\), not independent fixed-up/down constraints. Degenerate blocks require the FD divided-difference limit \(f'\), not deletion of equal-energy entries.

Native support already exists:

- `LR_Modules/orthogonalize.f90:92-163`: static metallic occupation factors and near-degenerate limits.
- `LR_Modules/localdos.f90:105-130`: FD derivative/local-DOS construction.
- `LR_Modules/efermi_shift.f90:77-108`: integrates both spins, sets `def=-delta_n/dos_ef`, and adds `def*ldos`.
- `PHonon/PH/dfpt_kernels.f90:350-365`: applies this before the HXC kernel.

At nonzero q, a periodic \(\delta\mu\) has only Gamma support, but metallic/degenerate static population response still matters.

The existing isolated finite-response implementation skips equal-energy commutator terms (`finite_fermion_response.py:7-18`); that is not a substitute for the static FD derivative. Likewise, collisionless collinear dynamics does not relax uniform spin populations merely because the static reference uses relaxed magnetization.

### Conjugacy

Retain complex cell-periodic fields and actual k/PW maps:

- \(g^{-q}=(g^q)^\dagger\), with source/target spaces exchanged.
- The static real-functional kernel obeys the corresponding \(K_{-q}=K_q^*\) relation after reciprocal-label mapping.
- Real time-dependent fields pair \((q,z)\) with \((-q,-z^*)\), **not generally \((-q,z)\)**.
- At half-b1, \(-q\equiv q\) modulo a reciprocal vector. This requires a reciprocal-index/envelope phase transformation; it does not make the primitive-cell envelope pointwise real.
- The registered alternating real supercell coordinate is self-conjugate and must not be counted twice.
