### 2. Exact density construction

#### Actual native format

`charge-density.dat` is **Fortran sequential unformatted reciprocal-space data**, not a real-space grid dump.

From `/opt/qebuild/q-e-qe-7.5/Modules/io_base.f90:405-597`:

| Record | Payload |
|---|---|
| 1 | `LOGICAL gamma_only`, `INTEGER ngm_g`, `INTEGER nspin` |
| 2 | `REAL(DP) b1(3), b2(3), b3(3)` |
| 3 | `INTEGER mill_g(3,ngm_g)` |
| Following records | One `COMPLEX(DP) rho_g(ngm_g)` record per spin component |

The reciprocal vectors in this file are **physical reciprocal vectors**, because `PW/src/io_rho_xml.f90:55-64` passes `tpiba*bg`.

For this collinear state, the two components are **total density and magnetization density**, not independent up/down densities. See `PW/src/sum_band.f90:303-307`; `io_rho_xml.f90:184-191` also obtains total magnetization as `omega*rho%of_g(1,2)`.

#### Replication formula

For \(A'=(2a_1,a_2,a_3)\),

\[
B'=(b_1/2,b_2,b_3),
\]

and, separately for total density and magnetization,

\[
\rho'(H,K,L)=
\begin{cases}
\rho(H/2,K,L),&H\text{ even},\\
0,&H\text{ odd}.
\end{cases}
\]

**Do not multiply the coefficients by two.** Density is unchanged locally; doubled volume produces doubled electron number and magnetization.

The observed dimensions make this an exact commensurate-grid transfer:

- Primitive XML: FFT **24×24×24**, **4645** density G vectors.
- Four-atom stdout: FFT **48×24×24**, **9271** density G vectors.
- Both use 240 Ry density cutoff and `gamma_only=false`.

The primitive state has 19 electrons and magnetization approximately `0.9999993014939200` Bohr/cell. The replicated starting density therefore has 38 electrons and approximately `1.9999986029878400` Bohr/supercell, without imposing a magnetization constraint.

#### Essential implementation detail: native ordering

**Writing correct Miller indices is insufficient.** In the ordinary same-`gamma_only` path, `read_rhog` skips the stored Miller-index record and distributes coefficients by index:

- `Modules/io_base.f90:713-779`.

Consequently, the writer must generate the **target native global G ordering**, not append the primitive arrays or merely change their Miller indices.

The exact source algorithm is:

1. `Modules/recvec_subs.f90:119-190`: enumerate Miller triples in the FFT bounds, retain vectors satisfying the density cutoff.
2. `Modules/recvec_subs.f90:195-200`: order using `hpsort_eps(...,eps8)`.
3. `Modules/sort.f90:9-134`: actual tolerance-aware heapsort, including original-index tie-breaking.

For this target, the enumeration bounds are \(H=-23,\ldots,23\), \(K,L=-11,\ldots,11\). Use QE’s dimensionless `bg` and `gcutm=ecutrho/tpiba²` in the ordering calculation. **Do not substitute ordinary NumPy sorting or an arbitrary equal-shell order.** The QE sort even documents a tolerance non-transitivity caveat.

The small missing density implementation is therefore precisely:

```text
fold_density_2x1x1(source_save, target_cell, target_fft, destination):
    read source sequential records and preserve their numeric representation
    generate target native density-G order using ggen + hpsort_eps
    for each target Miller triple:
        copy source coefficient at (H/2,K,L) if H is even
        otherwise write zero
    write target reciprocal vectors, target Miller list, both density components
```

No interpolation, cutoff reduction, coefficient thresholding, kernel fit, or fake XML is needed.

### 3. Full WFC preservation is also constructive

This is not blocked by the collected-save metadata contract. **Use QE’s existing raw distributed-WFC initialization path instead of constructing a fake collected save.**

#### Exact folding map

The actual primitive k ordering pairs as follows:

| Target k index | Primitive WFC indices combined |
|---|---|
| 1 | 1 and 5 |
| 2 | 2 and 6 |
| 3 | 3 and 7 |
| 4 | 4 and 8 |

For each spin, primitive \(k_1=0\) and \(k_1=-1/2\) fold into the same supercell \(K_1=0\):

\[
(h,k,l)\mapsto
\begin{cases}
(2h,k,l),&k_1=0,\\
(2h-1,k,l),&k_1=-1/2.
\end{cases}
\]

Embed each primitive orbital in its corresponding even/odd sector, zero the other sector, and concatenate the two 20-band sets.

**Keep the plane-wave coefficients unchanged.** In QE’s normalized plane-wave basis, the supercell basis supplies the larger-volume normalization. Multiplying coefficients by \(1/\sqrt2\) would incorrectly reduce their norm.

The resulting orbitals are orthonormal because the two branches have disjoint Fourier support. Their physical supercell wavefunctions are the normalized extensions of the primitive Bloch states.

#### Source WFC record format

`Modules/io_base.f90:25-205` writes:

1. `ik, xk(3), ispin, gamma_only, scalef`
2. `ngw, igwx, npol, nbnd`
3. `b1(3), b2(3), b3(3)`
4. `mill_k(3,igwx)`
5. One complex coefficient record per band.

Here `xk` and reciprocal vectors are physical reciprocal coordinates, and PW uses `scalef=1`.

**Collected-file order is not simply kinetic-energy order.** `PW/src/pw_restart_new.f90:979-1031,1053-1134` compresses the occupied subset of global density-G indices into increasing global-index order. The stored Miller list lets the folding implementation recover each coefficient’s actual Fourier label.

- QE prints `Starting wfcs from file`.
