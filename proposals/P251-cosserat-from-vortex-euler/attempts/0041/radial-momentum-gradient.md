# Radius-momentum gradient: the companion required by optical dispersion

This is an in-scope continuation generated by the complete twist variation.
The angle's canonical momentum in 0036 is a radius imbalance, so its spatial
gradient is not an unrelated correction. Keeping its energy avoids an
incorrect optical coefficient after elimination of that momentum.

## General local volume-preserving generator

For a transverse area-preserving flow with divergence-free generator `g`
on a core support, define `A=f g`, `B=div A`. Its axial pushforward has
first variation `(q' A,-q B)`. Retaining its complete second variation and
subtracting the zero-wavenumber angular Hessian gives exactly the same
positive gradient form as in full-biot-savart-twist.md:

```
C_g,h(k)=rho integral (P_T Ahat_g)^* . (P_T Ahat_h)
                       /(|xi|^2+k^2) d^2xi/(2 pi)^2.
```

This includes rigid translations of individual smooth cores as well as
their rotations. Different core generators are joined by disjoint-support
Hamiltonian cutoffs; no transverse compression of a core is used.

## Relative-radius generator and coefficient

At fixed `S=2d^2`, the relative coordinate is
`x=(r_1^2-r_2^2)/S`. At the regular hexagon its centroid variation is

```
delta X_a = s_a X_a x/2,
s_a=+1 on triangle 1, -1 on triangle 2.
```

The core profiles translate rigidly in this variation. Consequently

```
A_x = (1/2) sum_a s_a f_a X_a,
B_x = div A_x,
C_x = rho integral |P_T Ahat_x|^2/|xi|^2 d^2xi/(2 pi)^2 > 0.
```

The integral is finite because each triangle's centroid sum is zero. It is
strictly positive: on each nonzero core the curl of `f_a X_a` is a nonzero
directional derivative, since a nonzero compactly supported function cannot
be constant along that direction. Disjoint supports exclude cancellation.

For the relative angle `q=chi-pi/3` with common angle fixed, use
`A_q=(A_1-A_2)/2`, and write its coefficient as `C_q`. Reflection symmetry
makes the radial-angle gradient cross term exactly zero: the radial
generator is a polar vector under reflection, while the angle generator
has the opposite parity. Both coefficients have the same singular part,

```
C_x = 3 rho Gamma^2 d^2/(8 pi) log(d/epsilon)+O(rho Gamma^2 d^2),
C_q = 3 rho Gamma^2 d^2/(8 pi) log(d/epsilon)+O(rho Gamma^2 d^2).
```

These coefficients are not declared equal at finite core size; their exact
projector integrals differ.

## Exact quadratic elimination and a local derivative representation

Let `h=(H_epsilon)_xx>0`, `K=(H_epsilon)_{chi chi}>0`, and
`P0=3 rho Gamma S/4`. To the leading axial-gradient order, the exact
first-order affine action is

```
L2 = -P0 x qdot - h x^2/2 - K q^2/2
                   - C_x x_z^2/2 - C_q q_z^2/2.
```

Its momentum elimination gives the positive nonlocal kinetic operator

```
I(k)=P0^2/(h+C_x k^2),
omega^2(k)=(h+C_x k^2)(K+C_q k^2)/P0^2
```

at this derivative order. Thus the `C_x` term changes optical dispersion
already at order `k^2`. It is not analogous to a macroscopic cage-gradient
term whose mode amplitude supplies an additional power of `k`.

A local collective field can normalize the kinetic term: define

```
q(k)=sqrt(1+C_x k^2/h) Psi(k).
```

Its derivative expansion is
`q=Psi-(C_x/(2h)) partial_z^2 Psi+...`; the field agrees with the physical
angle at zero wavenumber. The leading local action then has unchanged
`I0=P0^2/h`, unchanged `K`, and

```
C_effective = C_q + (K/h) C_x > 0.
```

The point-core hexagon limit has `K/h -> 9`, so the singular contribution
to this free-relative-angle effective coefficient is ten times the singular
`C_q` contribution alone. This factor is a consequence of the companion
radius gradient, not an input to either microscopic coefficient.

At finite core size and before a macroscopic cage constraint, the preceding
is the free relative sector. The complete common/relative two-triangle
matrix and any later affine-cage field map must retain the analogous
momentum-gradient correction before continuum coefficients are identified.
This file does not substitute the free-relative coefficient for the
different constrained collective field.

## Full matrix rule before an affine cage identification

In canonical triangle variables write the radial-momentum gradient matrix as
`C_p`, the angle-gradient matrix as `C_theta`, the inverse momentum Hessian
as `M0=H_pp^(-1)`, and the angular Hessian as `K_theta`. Then

```
M(k)=(H_pp+k^2 C_p)^(-1)
    =M0-k^2 M0 C_p M0+O(k^4).
```

After a constant collective map `theta=T(Psi,beta)`, put
`N=T^T M0 C_p M0 T`. If that map diagonalizes the zero-gradient kinetic
term with scalar entry `J_Psi`, the leading optical local coefficient after
the affine cage identification is

```
C_Psi,effective = (T^T C_theta T)_{Psi Psi}
                   + K_Psi N_{Psi Psi}/J_Psi.
```

The terms involving cage gradients still have their appropriate extra
macroscopic derivative; the pure `Psi` entry of `N` does not. This formula
is the one to use for the constrained collective field rather than the
free-relative factor ten.

All matrices in that formula have finite-core definitions. In particular
`H_pp` is the momentum Hessian of the renormalized rotating Euler Hamiltonian
restricted to the smooth-core trial family. It is positive for sufficiently
small cores by the same uniform Hessian convergence as in 0036. At the
regular hexagon, the generator for triangle canonical momentum `p_i` is

```
A_{p_i}=-(1/(3 rho Gamma d)) sum_{a in triangle i} f_a e_a,
e_a=X_a/d.
```

Substituting these generators into the projector Gram integral defines the
complete matrix `C_p`, including its finite mutual terms. Reflection removes
every angle-momentum gradient cross entry. Triangle exchange gives
`M0=[[a,b],[b,a]]`, with `a>0`, `a>|b|`; its exact collective map is

```
s=(a+b)/a,  t=-b/a,
T=[[s,t],[0,1]],
J_Psi=s^2 a,  K_Psi=s^2 K_relative.
```

The exact leading-derivative constrained result can therefore be written
without any point-limit constants:

```
C_Psi,effective = s^2 [ (C_theta)11
 + (K_relative/a) (a^2 (C_p)11+2ab (C_p)12+b^2 (C_p)22) ] > 0.
```

Its positivity follows from the exact two Gram matrices and the positive
finite-core angular and momentum Hessians. The necessary local field
normalization agrees with the physical collective angle at zero wave number;
its order-two derivative correction is declared, not hidden in a fitted
wryness constant.

For checking the singular point-limit coefficients only, use the already
derived `M0=[[11I/10,-9I/10],[-9I/10,11I/10]]`,
`T=[[2/11,9/11],[0,1]]`,
`C_p=Tline I_2/(3 rho^2 Gamma^2 d^2)`, and
`C_theta=3 Tline d^2 I_2`. With `I=6 pi rho d^4` and
`K_relative=27 rho Gamma^2/(8 pi)`, the complete singular constrained
coefficient is `1129/220` times the twist-only singular coefficient
`(T^T C_theta T)_{Psi Psi}`. Finite-core values use their exact matrix
integrals; this ratio is not imposed on those values.
