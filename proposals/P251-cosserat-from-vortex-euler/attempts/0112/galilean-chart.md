# Exact independent centroid chart at zero macroscopic wave number

Let `u(t,x),p(t,x)` be the actual smooth Euler family underlying 0109.
Spatial translation and a constant Galilean boost give the exact family

```
uε(t,x)=u(t,x-ε(a+tV))+εV,
pε(t,x)=p(t,x-ε(a+tV)).
```

Its material flow is `gε(t,A)=g(t,A)+ε(a+tV)`, with correspondingly
translated initial tags. Linearization about the stationary base gives

```
ξG=a+tV,       vG=V-[(a+tV)·∇]u,
vG=ξG,t+[u,ξG].
```

The Euler residual vanishes exactly by differentiating the Euler equation;
no long-wave approximation is used at this zero-wave-number step. Actual
material moments and transported physical vorticity orientation transform as

```
δXG=a+tV,     δPG=MV,     δSG=0,     δΦG=0.
```

The intrinsic angular momentum is boost invariant because both centered
position and centered velocity are unchanged. Materially observed vorticity
is translated with the tag, so the translation does not fake a core angle.

Superpose these exact linearized solutions with the **actual**, not merely
approximate, optical solution. For arbitrary prescribed centroid initial
position and velocity, choose `a` and `V` to subtract the optical solution's
initial centroid and velocity. This gives an independent centroid
position/velocity chart alongside the optical coordinates at `k_macro=0`.
The subsequent centroid is `a+tV+Uopt(t)`, with the optical pressure
acceleration retained; it is not asserted to be dynamically uncoupled.

The boost is a nondecaying mean-sector variation. The optical perturbation
was normalized in the decaying whole-space Leray sector. These are not
the same velocity normalization: `V·dx=d(V·x)` changes no Kelvin circulation
on R³, but a nonzero constant velocity is not the decaying inverse-curl
solution at fixed mean. Finite parcel mass and momentum are legitimate;
an infinite whole-space boost energy is not silently inserted in an L²
optical action. The spatial-translation component similarly transforms the
actual fixed-Kelvin datum by material relabeling of its coordinates.

This symmetry result supplies independent physical mean initial data, not
extra angular polarizations, finite-wave-number shear closure, or an Euler
continuum theorem. In particular the 0109 branch remains its circular
two-real-dimensional optical family.
