# 0079 — compact-background alternative: source reconnaissance

Main considered an alternative way to assemble bounded material RVEs:
exact smooth compactly supported stationary Euler cells separated by quiescent
ambient fluid. This changes the background construction, not the user's
objective. It could make mass-centroid accounting simpler, but it must retain
the requested EPS-type vortex structure and derive the same physical action.

Primary-source search identified Gavrilov's *A steady Euler flow with compact
support* (arXiv:1810.08020), which constructs a nontrivial smooth stationary
3D flow. It does not by its abstract supply the arbitrary knotted-tube
construction used by the current EPS route. Enciso and Peralta-Salas's 2023
survey, *Beltrami fields and knotted vortex structures in incompressible fluid
flows*, section 8, explicitly lists compactly supported stationary solutions
with vortex tubes of arbitrary topology as an open problem at publication.
Its stated known compact solutions are axisymmetric with unknotted tubes.

Sources consulted:
- https://arxiv.org/abs/1810.08020
- https://londmathsoc.onlinelibrary.wiley.com/doi/10.1112/blms.12780

Verdict on using these sources as an immediate replacement: blocked by the
missing knotted compact-cell construction. This is source applicability, not
a proof of nonexistence, a claim that the problem remains open in all later
literature, or a scientific-exhaustion certificate. No compact-EPS theorem
is imported from an abstract or inferred by multiplying a Beltrami field by
a cutoff. The active finite-parcel and ambient-inclusive routes 0075/0078
continue without requiring compact support of the whole background.
