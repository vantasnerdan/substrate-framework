# Terminal Campaign or External PR Achievement

Use for an existing external PR or a campaign with complete success/certified
exhaustion. Active campaigns use research-arc/campaign-proposal and branch
checkpoints. Apply research-pr-harvest for its exact lifecycle and evidence rules.
Apply the shared reward and evidence contract in `AGENTS.md` and the applicable
skill. Fill sections with concrete evidence, not repeated policy. Begin each
section with a prose sentence for memory-index disclosure.

## Objective and Accepted Frontier
State the user goal, strongest useful result, release/accepted boundary, working
tree and live PR lifecycle. Keep artifact merge, claim promotion and parent
completion separate. Link proposal, invariants/imports, candidate choice (two
open mechanisms or one fixed theorem), criteria and comparator exposure.

## Contribution and Terminal Evidence
Name the reusable object/claim/closure; narration alone does not derive a mechanism.
For a terminal campaign link complete success or reviewed exhaustion. A newly
discovered scientific route returns execution to the campaign branch; recertify
terminal state before refreshing the PR.

## Units and Ownership
Group coherent reusable units with positive statement, dependencies, evidence,
consumers, and headline independence. Record merge unchanged, correct then merge,
or history only. Give authorized workers raw inputs, bounded tasks and disjoint
surfaces; supervisor owns approach, alternatives and integration.

## Constructive Review and Correction
Use one substantive pass plus one bounded correction check. Current repairs
name a falsifier, circular/missing step, unsupported used dependency or affected
consumer. Preserve the strongest meaningful positive result; adjacent observations
remain follow-up unless new evidence changes their effect. Name one stale check
per repair, not a new cycle for prose/tallies.

## Framework Fit and Validation
State invariant compatibility and declared assumptions. Independent canon conflict
earns a separate challenge/revision with competing repairs and migration; a
truthful conditional artifact keeps its stated utility without claim promotion.
Record analytic closure and named numerical remainder where applicable, oracle
and sensitivity, solver/refinement/error, targeted APIs, consumer replay,
validate_changed.py scope, registry/generation/memory and whitespace checks.
One content-addressed receipt covers the frozen boundary; only changed predicates
earn reruns. Resolve hidden premises/promises/broken consumers inside selected
units; keep honest hypotheses and open parent work as frontier.

## Landing, Authority and Next Achievement
Record accepted claims or none, API/test paths, campaign/release/docs/memory as
applicable, reviewed PR and landed commit. Update the canonical issue with landed,
correct-next and history-only units (None when empty), evidence, goal state and
one decisive next construction/question/distinction. Preserve active refactor/
harvest until landing or evidenced terminal-close.
Existing-PR review can finish at an operational disposition; active campaigns
continue their positive objective. Explicit user pauses earn durable resume state.

## Cross-References
Link parent/child contracts, proposal, source, claims, evidence, release and issue.
